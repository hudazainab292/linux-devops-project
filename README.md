# Linux Server Monitoring Project


## 1. Project Overview

This project demonstrates practical Linux system administration skills through server monitoring and automated backup operations.

The goal is to monitor Linux server performance, manage system resources, and automate important administrative tasks using Bash scripting.


## 2. Project Objectives

- Monitor CPU utilization.
- Check memory usage.
- Monitor disk space.
- Check system uptime.
- Create automated backups.
- Generate system health reports.
- Identify potential server issues.


## 3. Technologies Used

- Operating System: Ubuntu Linux
- Scripting Language: Bash
- Version Control: Git
- Code Repository: GitHub


## 4. Linux Commands Used
